# Сити Маркет — план реализации по ТЗ v1.1 (актуальный)

## 0. Как пользоваться

### Цепочка документов
1. `Финал ТЗ.txt` (v1.1) — первоисточник.
2. **`TZ_V1_1_STATUS.md`** — единый актуальный статус (code-verified). Источник правды по «что уже есть».
3. **`TZ_V1_1_PLAN.md`** (этот файл) — задачи, порядок, проверка, статусы.

> Заменяет `TZ_V1_1_IMPLEMENTATION_PLAN.md` (он рассинхронен с кодом). Старые `TZ_V6_*` — про v0.6, не использовать.

### Порядок
Сверху вниз: **P0 → P1 → P2 → P3**. P0 — корректность и чистка конфликтов (без этого продавец/модерация/финансы делать рискованно). Клиентские блокеры — раздел C.

### Статусы
`⬜ TODO` · `🟦 IN PROGRESS` · `✅ DONE (code)` (реализовано+самопроверка, человеком не подтверждено) · `🟢 VERIFIED` (проверил человек) · `⛔ BLOCKED` (ждёт заказчика) · `🟡 PARTIAL`.

### Правила
1. Взял → `🟦`. Закончил → `✅ DONE (code)` + заполни «Изменения». «Проверено человеком: нет».
2. Уперся в данные клиента → `⛔ BLOCKED`, укажи код C-XX.
3. Человек в конце вручную (вкл. адаптив §27 и состояния §28) → `🟢 VERIFIED`.
